# Original site archive

Saved on October 23, 2026 from the working tree on `FA26redesign`, before creating the replacement layouts.

- `original/` preserves the original directory structure and file bytes: pages, collections, layouts, includes, data, images, fonts, SCSS, scripts, README, license, Gemfile, Gemfile.lock, configuration, dotfiles, and GitHub workflow.
- `CONTENT.md` combines all Markdown, HTML, YAML, and JSON files for browsing and searching. This includes content embedded in layouts and commented template samples. Nothing has been selected for deletion.
- `manifest.json` records each archived file's relative path, byte length, and SHA-256 checksum.

This is a working-tree snapshot, not a second Git repository. Includes were already located in `_data/_includes/` when this snapshot was made; that location is preserved. Git history remains in the repository's existing `.git` directory.

Generated output (`_site`), Jekyll/Sass caches and metadata, dependency installation directories, and Git internals are excluded. These are reproducible build/runtime files rather than source content. Any `_site` folder left in the working tree has not been deleted.

Jekyll ignores this underscore-prefixed folder during the normal root build. The new scaffold lives separately in `_rebuild/`.
